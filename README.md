# Healthcare-Project
Healthcare Insurance-Hospital Data Analysis Project

Conducted end-to-end data preparation, transformation, and visualization for a healthcare dataset containing over 12,500 records representing relationships between 7 hospitals and 7 insurance providers.

Key Responsibilities:
Collected and consolidated healthcare insurance network data from multiple sources.
Performed extensive data cleaning and validation using Microsoft Excel and Power Query, including:
Removing duplicates and inconsistencies.
Standardizing hospital and insurance provider information.
Handling missing and invalid data.
Creating structured datasets for analysis.
Designed and optimized data transformation workflows in Power Query to improve data quality and reporting efficiency.
Developed interactive dashboards in Power BI to visualize:
Hospital-insurance provider relationships.
Coverage distribution across providers.
Key performance indicators (KPIs) and summary metrics.
Created dynamic filters and drill-down capabilities to enable detailed analysis by hospital, insurance company, and coverage category.
Delivered actionable insights through data visualization, supporting decision-making and improving visibility into healthcare provider-insurer partnerships.
Tools & Technologies
Microsoft Excel
Power Query
Power BI
Data Cleaning & Transformation
Data Modeling
Dashboard Development
Healthcare Data Analysis
Project Impact

Successfully transformed a large healthcare dataset of 12,500+ records into a reliable analytical model and interactive reporting solution, enabling stakeholders to efficiently monitor and analyze relationships between hospitals and insurance providers.
